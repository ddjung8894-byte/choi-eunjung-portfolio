# CHOI EUNJUNG · Personal Portfolio

최은정의 경력과 작업, 최근 개인 프로젝트를 소개하는 웹사이트입니다.

- Website: https://ddjung8894-byte.github.io/choi-eunjung-portfolio/
- HTML, CSS, JavaScript로 만든 정적 웹사이트입니다.
- GitHub Pages에서 `main` 브랜치의 루트를 게시합니다.
- 공개 화면에 사용하는 파일만 포함합니다.

상업 작업물의 권리는 각 권리자에게 있으며, 본인의 기여 내용을 소개하기 위한 포트폴리오 자료입니다.


## 페이지 구성

소개 → 작업(타이거스톤 · 웹앱 · 영상 · 작은 실험) → 할 수 있는 일 → 칼이쓰마 실무 사례와 경력 → 기록 → 이메일 연락처 순서입니다.
현재 프로젝트는 TIGERSTONE, 매일매일, PaceKit 순서이며 Review Mate는 작은 실험으로 구분합니다.

## Version 2 · 2026-10-03

주황·차콜 색상과 기존 콘텐츠 구조를 유지하며 첫 화면, 작업 이미지 배치, 역량 카드를 다듬었습니다.

- 첫 화면: “궁금한 건 파고들고, 필요한 건 만듭니다.”
- 역량: 같은 색감으로 생성한 3D 일러스트 5장과 흰 카드. 웹용 이미지 합계 약 150KB.
- TIGERSTONE: 스토브 출시 링크, 대표 이미지, 공식 트레일러, 개발기 영상.
- THE FIRST FILE: 대표 쇼츠 2편. 클릭할 때 영상 로딩.
- 2011 다큐멘터리: 실제 영상에서 발췌한 스틸 2장.
- 기존 경력·수상·교육·상업 작업의 사실관계와 원본 이미지 유지.

기존 버전은 Git의 `eb092ee` 커밋에서 확인할 수 있습니다.
기본 스타일은 `styles.css`, 버전 2의 시각적 조정은 `v2.css`에 있습니다.

## 가독성 정리 · 2026-10-03

사진 뒤의 장식을 줄이고 Hero에 대표작 상태와 작업·연락 버튼을 배치했습니다. 타이거스톤의 대표 이미지와 핵심 설명을 나란히 묶고, 영상 썸네일과 역량 이미지를 작게 조정했습니다. 웹앱 데모 버튼은 항상 표시하며 역량에서 관련 작업·경력으로 이동할 수 있습니다. 경력 링크는 해당 상세를 펼칩니다.

1440 / 390 / 360px 실제 뷰포트, 메뉴와 CTA, 원본 이미지 팝업 5개, 영상 재생 4편, 경력 10개 펼침, 키보드·모션 전환을 확인했습니다. 외부 웹앱 3개 모두 `?demo=1` 예시 화면 진입을 확인했습니다. 기존 사진·영상·작업 원본과 경력 사실은 유지하며, 배민 상세에만 확인된 병행 근무 설명을 추가했습니다.
