# CHOI EUNJUNG · Personal Portfolio

최은정의 경력과 작업, 최근 개인 프로젝트를 소개하는 웹사이트입니다.

- Website: https://ddjung8894-byte.github.io/choi-eunjung-portfolio/
- HTML, CSS, JavaScript로 만든 정적 웹사이트입니다.
- GitHub Pages에서 `main` 브랜치의 루트를 게시합니다.
- 공개 화면에 사용하는 파일만 포함합니다.

상업 작업물의 권리는 각 권리자에게 있으며, 본인의 기여 내용을 소개하기 위한 포트폴리오 자료입니다.


## 페이지 구성

소개 → 작업(현재 개인 프로젝트 · 칼이쓰마 실무 사례) → 할 수 있는 일 → 경력 → 기록 → 이메일 연락처 순서입니다.
현재 프로젝트는 TIGERSTONE, 매일매일, PaceKit 순서이며 Review Mate는 작은 실험으로 구분합니다.

## 추가 자료 필요

- TIGERSTONE: 실제 대표 게임 스크린샷 1장, 플레이 화면 1~2장, UI 화면 1장.
- 〈익숙하고도 낯선 시간 / Vintage 2011〉: 실제 다큐멘터리 스틸 1~2장.
- 현재 이 두 작업에는 대체 이미지를 넣지 않았습니다. 공개 가능한 이미지가 준비되면 추가합니다.

## 검수 · 2026-10-01

360 / 390 / 768 / 1024 / 1440px 화면, 메뉴 이동과 활성 표시, 이미지 로딩, 경력 details 10건, 작업 모달 5개, Tab·Shift+Tab·Escape, skip link, 모션 전환 및 reduced-motion을 확인했습니다.
기존 경력 내용과 원본 작업 이미지를 보존했습니다. 공개 연락처는 이메일만 제공하며 첫 화면의 나이 표기를 제거했습니다.
프로필의 원본 PNG는 보존하고, 화면에서는 38KB WebP 파일을 사용합니다.
